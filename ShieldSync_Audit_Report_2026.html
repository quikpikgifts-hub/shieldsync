2.2 Data Architecture & Persistence

The data abstraction layer (src/db.js) exports eight table interfaces — incidents, officers, equipment, leave, visitors, scans, audit, and users — each exposing .list(), .get(), .insert(), .update(), .remove(), and .subscribe(). The interface is identical to Supabase's JavaScript client, meaning the backend can be switched from localStorage to real Postgres with zero changes to App.jsx. This is a strong architectural decision.

⚠ Critical Gap — Data Persistence

All data currently lives in the browser's localStorage. There is no cross-device sync, no multi-user state sharing, and no data survival across browser clears. A dispatcher on one machine cannot see updates from an officer on another. This is the single highest-priority blocker for production deployment. Resolution requires setting two environment variables in Vercel: VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY.

🔴 Critical — Plaintext Credentials in Demo Mode

AUTH_USERS stores plaintext passwords in the client bundle and in localStorage. This is acceptable for a demo environment but is a critical blocker for any production deployment. Resolution: replace with Supabase Auth (bcrypt), remove AUTH_USERS from the client bundle, and add server-side session management.

ℹ SOC 2 Type II — Recommended Immediate Action

Enterprise contracts with companies over 500 employees require SOC 2 Type II. The audit engagement takes 6–12 months. Starting in June 2026 means earliest completion is Q4 2026 / Q1 2027. The audit log module, RBAC implementation, and security headers provide a strong evidence base for the trust service criteria. Recommendation: engage a SOC 2 auditor in July 2026.

SECTION 09 — PRIORITY ACTION PLAN
Section 09
Priority Action Plan
Ordered by impact and effort. Items 1–3 are immediate and require no code changes.

This Week — Zero Code Required

  • 1
    Set ANTHROPIC_API_KEY in Vercel Dashboard
    Takes 5 minutes. Unlocks AI Report Generation, AI Command Center, and AI Copilot across all modules — the primary competitive differentiator that currently returns errors. Go to Vercel → Project → Settings → Environment Variables.
  • 2
    Connect Supabase Backend (VITE_SUPABASE_URL + VITE_SUPABASE_ANON_KEY)
    Create a Supabase project, run the schema migration (8 tables already defined in db.js), and set two environment variables. Zero App.jsx changes needed. This converts the platform from a single-user demo to a production multi-tenant system.
  • 3
    Publish Marketing Landing Page
    A prospect URL must exist before any sales activity. Merge or rebuild PR #1. The personalized demo wizard makes this especially powerful — the landing page CTA becomes "Try a demo customized to your company" with zero friction.

Next 30 Days — High-Impact Builds

  • 4
    SOS → Real Notification Delivery (Twilio SMS via Edge Function)
    The SOS button currently fires an in-app toast only. In the field, a supervisor and emergency contact need an SMS within 8 seconds. Build a Vercel Edge Function that calls Twilio on SOS trigger. This is a legal and operational requirement for any real deployment.
  • 5
    Live GPS on Ops Map (Browser Geolocation + Supabase Real-Time)
    Wire navigator.geolocation.watchPosition() (already imported in db.js) to update officer positions in Supabase. Subscribe to changes in OperationsMapModule. This closes the biggest feature gap vs. TrackTik and makes the Ops Map genuinely live.
  • 6
    Missed Checkpoint Auto-Escalation Rules
    If a checkpoint is not scanned within the patrol window, automatically alert the supervisor via in-app notification, SMS, or push. A configurable rules engine in Company Settings (e.g., "if checkpoint X not scanned in 90 min, notify [role]") closes a top-3 operational ask.
  • 7
    Digital E-Signature on Reports, Post Orders & Inspections
    Canvas-based signature pad for officer sign-off. Required for legally defensible documentation. Every competitor has this — most charge extra for it. A well-built canvas component reused across IncModal, PostOrders, and InspModal closes this gap in one build.

60–90 Days — Enterprise Readiness

  • 8
    SAML 2.0 / SSO Integration (Okta, Azure AD)
    No enterprise IT department will provision 500+ accounts manually. SAML 2.0 is a hard procurement requirement for any company over 200 employees. Implementation via passport-saml in an Edge Function. Estimated 2–3 week build. Unlocks every enterprise deal gate G2.
  • 9
    Begin SOC 2 Type II Audit Engagement
    Engage a SOC 2 auditor in July 2026. The audit takes 6–12 months. The existing audit log, RBAC enforcement, security headers, and data architecture provide a strong evidence base for all five trust service criteria. Without SOC 2, enterprise contracts over $50K/year are effectively unwinnable.
  • 10
    Publish REST API + 3 Webhook Events
    Expose a tenant-scoped REST API from the Supabase layer. Minimum viable: incident creation webhook, officer clock-in webhook, and SOS webhook. Add a Zapier integration for two common workflows (incident → Slack, checkpoint miss → SMS). Enterprise architects require integration proof before recommending internally.
